✨ Features

- 🤖 AI-powered LinkedIn post generation
- 🌐 Hinglish, Hindi, and English
- 🎯 Professional, Friendly, and Motivational tones
- 📝 Short, Medium, and Long posts
- 📋 Copy Post feature
- 📥 Download Post feature
- 🎨 Modern dark-themed interface

🛠️ Technologies Used

- Python
- Streamlit
- OpenRouter API
- OpenAI Python SDK

💻 Run Locally

1. Clone this repository:
   
   git clone https://github.com/GauravPatel147/ai-linkedin-post-generator.git

2. Open the project folder:
   
   cd ai-linkedin-post-generator

3. Install dependencies:
   
   pip install -r requirements.txt

4. Create a ".env" file containing your OpenRouter API key:
   
   OPENROUTER_API_KEY=your_api_key_here

5. Run the app:
   
   python -m streamlit run app.py

🔐 Security

Never upload your ".env" file or API key to GitHub.
